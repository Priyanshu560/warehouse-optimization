1. Who is responsible

This site is a demo dashboard for a warehouse order-batching and picker-routing project (the “Project”). The person or organisation responsible for it is the project author, contactable at [CONTACT EMAIL – to be supplied] (and [POSTAL ADDRESS, optional – to be supplied]).

2. Short version

The dashboard has no sign-up, login, contact form, comment box, payment, or newsletter. It does not ask you for any personal information, does not set cookies, does not use analytics or advertising trackers, and does not load fonts, scripts or other files from third-party servers. The pages you are viewing are static files.

3. What the dashboard shows

The dashboard displays precomputed results from a bundled sample dataset of orders, products and bin locations. These are demo figures, not results from a real warehouse. The data exported to the dashboard contains order, batch and location identifiers and aggregate distances and times. It does not contain customer names or contact details.

4. What happens in your browser

  • Everything is computed and drawn locally in your browser from files served with the page. Nothing you click, select or type into the batch search box is sent anywhere by the dashboard.
  • “Export batch table (CSV)” builds a file in your browser and saves it to your device. It is not uploaded.
  • The dashboard does not store anything in cookies, localStorage, sessionStorage or IndexedDB (see the Cookie Policy).

5. Hosting and server logs

If these pages are served from a web host, that host’s servers normally receive technical information with each request (for example your IP address, browser type and the page requested) and may keep it in access logs. The Project itself adds no logging or tracking code. Hosting provider: [HOSTING PROVIDER / WHERE PUBLISHED – to be supplied]. Log retention period: [LOG RETENTION – confirm with host]. If you only open the files from your own computer, no request leaves your device.

6. If you run the Python tool with your own data

The command-line tool reads CSV files from your own machine and writes reports back to your machine. It does not send data over the network. The order file may contain an optional customer column, but the tool does not need it and does not use it in batching, routing, reports or the dashboard export, so you can omit it. If you load real personal data, you are responsible for having a lawful basis for it and for protecting the files and outputs.

7. Purposes

Because the dashboard does not collect personal data from visitors, there is no visitor-data processing purpose to describe. The Project does not make automated decisions about individuals.

8. Sharing and transfers

The dashboard does not share visitor data with third parties and makes no requests to third-party services. Any sharing at the hosting layer is described in section 5.

9. Children

The dashboard does not knowingly collect personal data from anyone, including children.
