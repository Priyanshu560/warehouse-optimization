Cookie Policy

Draft prepared 29 September 2026. Not yet reviewed by a lawyer.

Draft notice: this page describes only what the project does today. Items highlighted like [this] are business or legal details that the project owner must supply; they have deliberately not been guessed. Remove this notice once those are filled in and the text has been reviewed.

1. Summary

This dashboard does not set or read cookies, and does not use localStorage, sessionStorage or IndexedDB. Because of that, it does not show a cookie banner: there is nothing to ask consent for.

2. What we checked

TechnologyUsed?
First-party cookiesNo
Browser storage (localStorage, sessionStorage, IndexedDB)No
Analytics, advertising trackers, pixels, fingerprintingNo
Third-party fonts, scripts, maps, videos or embedsNo (the dashboard uses your device’s system fonts and its own files only)

3. Hosting layer

The Project’s own code sets no cookies. If the site is published on a host or CDN that adds its own cookies or logging, that would be outside the Project’s code. Hosting provider: [HOSTING PROVIDER – to be supplied; confirm whether it sets any cookies].

4. If this changes

If analytics, embeds, or any feature that uses cookies or similar storage is added later, this policy will be updated and, where consent is required, a consent mechanism will be added before the feature is switched on.
